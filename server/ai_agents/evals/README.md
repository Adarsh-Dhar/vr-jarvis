# Agent Evaluation Tests

The in-process golden-task runner (`runner.py`) was removed: it returned
`not_implemented` for every task and did not exercise the server's evidence
checks, approval gates, or HTTP contract.

Live evaluation now lives in `jarvis-agent-evaluation/`:

- `runner/http_runner.py` — runs benchmark cases against a live server's `/ask`
  and scores accuracy, fabrication, latency, and token usage.
- `runner/agent_test_runner.py` — kept for mock-mode infrastructure checks only;
  its default (non-`--live`) results are not accuracy measurements.
- `benchmarks/` — generated by `scripts/gen_benchmark.py` from a graph index.
- `reports/` — per-run `results.jsonl` + `summary.json`; compare runs with
  `scripts/eval_compare.py`.

The `golden_tasks/` YAML files below remain as scenario definitions, but their
expected answers have not all been hand-verified — do not treat them as ground
truth until each one is checked against the repository.

## Directory Structure

- `golden_tasks/` - YAML files with known correct answers for each agent
  - `repository/` - Repository Intelligence agent tests
  - `code_understanding/` - Code Understanding agent tests
  - `relationship/` - Relationship Intelligence agent tests
  - `data_flow/` - Data Flow Intelligence agent tests
  - `software_engineering/` - Software Engineering agent tests
  - `testing/` - Testing and Verification agent tests
  - `visualization/` - Visualization and Spatial Intelligence agent tests
  - `orchestrator/` - Orchestrator agent tests

## Test Format

Each golden task is a YAML file:

```yaml
test_id: AGENT-XXX-001
agent: <agent_name>
fixture: <fixture_name>
request: <user_request>
expected_tools_include: [list of tools]
expected_findings:
  - claim_contains: <substring>
must_not:
  - <violation_type>
metrics: [tool_selection, evidence_accuracy, hallucination_rate, latency_ms]
```

## Fixtures

- `simple-python` - Basic Python project
- `spring-boot` - Java Spring Boot application
- `intermittent-bug` - Race condition and timing issues
- `polyglot-monorepo` - Multiple languages and frameworks
