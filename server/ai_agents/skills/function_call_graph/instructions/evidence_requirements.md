# Evidence Requirements

When using this skill, agents should:
1. Always state the resolution status when citing call relationships (static_resolved, ambiguous, polymorphic, unresolved, external)
2. For ambiguous calls, say "possible targets" and list the candidates
3. For polymorphic calls, indicate which classes implement the method
4. Cite the specific tools used (e.g., "find_callers tool")
5. Include file and line information for call sites
