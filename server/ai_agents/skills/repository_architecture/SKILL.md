# Repository Architecture Skill

## Overview
This skill analyzes and visualizes repository architecture, including module boundaries, language detection, and overall structure.

## Capabilities
- `visualize_architecture`: Generate architecture visualizations
- `analyze_architecture_boundaries`: Identify coupling between modules
- `detect_languages`: Detect programming languages used
- `index_repository`: Index repository structure
- `analyze_repository_structure`: Analyze repository organization

## Tools Used
- `visualize_architecture`: Architecture visualization tool
- `analyze_architecture_boundaries`: Boundary analysis tool
- `detect_languages`: Language detection tool
- `index_repository`: Repository indexing tool
- `analyze_repository_structure`: Structure analysis tool

## Permissions Required
- `repository.read`: Read access to repository files
