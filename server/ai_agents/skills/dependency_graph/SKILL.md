# Dependency Graph Skill

## Overview
This skill builds and analyzes module dependency graphs, including circular dependency detection and impact analysis.

## Capabilities
- `build_dependency_graph`: Build module dependency graph
- `visualize_dependency_graph`: Visualize dependency graph
- `find_circular_dependencies`: Detect circular dependencies
- `find_dependents`: Find dependents of a module

## Tools Used
- `build_dependency_graph`: Build dependency graph tool
- `visualize_dependency_graph`: Visualize dependency graph tool
- `find_circular_dependencies`: Circular dependency detection tool
- `find_dependents`: Find dependents tool

## Permissions Required
- `repository.read`: Read access to repository files
- `graph.read`: Read access to graph data
