# Rust Example Project

This is a simple Rust project used for multi-language testing of the JARVIS testing framework.

## Structure
- `src/main.rs` - Main entry point with functions
- `src/utils.rs` - Utility functions
- `src/models.rs` - Data models (User, Config structs)

## Purpose
To validate that:
- Language detection works for Rust files
- Symbol extraction finds functions, structs, and methods
- Dependency graph detects module dependencies
- Call graph identifies function calls

## Usage
Used by tests for:
- Language adapter tools
- Symbol extraction
- Dependency analysis
- Cross-language code understanding
