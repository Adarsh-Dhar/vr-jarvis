# Integration Test Infrastructure

This directory contains infrastructure for Layer 3 integration tests.

## Components

### Database Fixtures
- SQLite test databases
- PostgreSQL test schemas
- Test data for database-related tools

### API Fixtures
- Simple Flask API server
- Simple Express API server
- OpenAPI specifications
- GraphQL schemas

### Git Fixtures
- Test git repositories with various histories
- Branch configurations
- Commit patterns

### Runtime Fixtures
- Sample Python programs for runtime tracing
- Execution traces
- Application logs

## Setup

Run `setup.sh` to initialize all integration test infrastructure.
